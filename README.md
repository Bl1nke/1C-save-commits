1С парсинг коммитов
Эта обработка автоматически выгружает историю коммитов из Git-репозитория в справочники 1С, сохраняя хэши, авторов, даты и привязку к веткам. 
Скрипт самостоятельно клонирует или обновляет локальную копию репозитория, разбирает вывод `git log` и записывает только новые данные, предотвращая дубли. 
Для запуска достаточно установленного Git, созданных справочников «Ветки» и «Коммиты» и нажатия одной кнопки в интерфейсе обработки.
